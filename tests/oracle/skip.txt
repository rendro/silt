# that is known and reported, one per line:
#
#   <input> | <kind> | <what it is, and where it was reported>
#
# <input> is the input's name in the oracle's report, <kind> the kind of
# its finding (panic, compiler-bug, verifier, type-confusion,

# suite does not run it in its own: a full sweep (SILT_ORACLE_FULL=1)
# runs it through the `silt` command and fails when that ends with
# status 0 or 1.
