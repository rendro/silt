# Security

## Reporting a vulnerability

Report a vulnerability in silt privately, through GitHub:
[Report a vulnerability](https://github.com/rendro/silt/security/advisories/new)
(the repository's Security tab). Please do not open a public issue for
it.

Say what is affected (the `silt` binary, the library, the playground),
the version (`silt --version`), and how to reproduce it: a small
program is best.

## Supported versions

Fixes go into the next release. Only the latest release is supported;
`silt update` installs it.
